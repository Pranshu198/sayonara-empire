# Sayonara Empire — Economy Business Simulator

Real React + Vite rebuild of Sayonara Empire. AMOLED black, mobile-first economy/business simulator: 32 businesses, realistic P&L engine, stocks/gold/crypto, property, bank/loans/FD, SIP/bonds, rivals, missions, achievements, prestige. Day cycle with Manual/Auto time control.

Live: https://pranshu198.github.io/sayonara-empire/

## Dev
```
npm install
npm run dev
npm run build
```
